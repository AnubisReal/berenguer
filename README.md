# Berenguer

Base en blanco con React, TypeScript y Vite. Requiere Node.js 22.

```sh
npm ci
npm run dev
```

Para publicar, selecciona **GitHub Actions** en **Settings → Pages** del repositorio. El flujo de publicación se ejecuta al subir cambios a `main`. El dominio de Hostinger se configura mediante DNS una vez añadido en GitHub Pages.

## Redes sociales y WhatsApp

WhatsApp abre el chat de Berenguer en +1 941 977 1723. Puedes cambiarlo con `VITE_WHATSAPP_NUMBER`. Configura Facebook, Instagram y TikTok con `VITE_FACEBOOK_URL`, `VITE_INSTAGRAM_URL` y `VITE_TIKTOK_URL` en `.env.local` o en las variables del repositorio para GitHub Pages.
